## Статуси тікетів

### Backlog

Задачі, які заплановані на майбутнє, але ще не готові до виконання.

### Todo

Задача готова до виконання та має достатньо інформації для початку роботи.

### In Progress

Задача знаходиться в роботі. Розробник уже почав її виконання.

### Done

Задача виконана, перевірена та прийнята. Необхідний код об'єднаний у відповідну гілку.

## Git/Github

### branch

Відмежування від основної лінії розробки для продовження своєї частини роботи та уникнення конфліктів з основною лінією

### commits

Фіксація змін у файлах, що відстежуються Git

### PR

Pull Request - запит на злиття відповідної гілки зі змінами у спільну гілку проєкту

### review

PR перевіряється іншим розробником. За необхідності автор вносить виправлення та оновлює PR.

### merge

Об'єднує зміни з однієї гілки проєкту в іншу. Після успішного review та виконання всіх необхідних перевірок PR об'єднується з основною гілкою.

## Шаблони

### Щоденний звіт  

Являє собою коментар у поточному тікеті у вигляді:

- що вивчив;
- що реалізував;
- посилання на PR або назву активної гілки;
- що було незрозуміло або складно.
 
### Блокер

Якщо роботу неможливо продовжувати, до тікету додається  label blocked і коментар із зазначенням:

- що намагався зробити;
- очікуваного результату;
- фактичного результату;
- уже виконаних перевірок;
- тексту помилки або скриншота.
