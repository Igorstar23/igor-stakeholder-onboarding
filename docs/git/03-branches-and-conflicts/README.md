## Команди

- 'git switch -c' - створити нову гілку від поточної та переключитися на неї
- 'git merge' - залити зміни вказаної гілки в поточну

## Причина конфлікту

Було змінено одну й ту саму частину одного й того самого файлу по-різному у двох гілках, що об’єднуються.

## Пояснення markers

Під час конфлікту Git використовує спеціальні markers в конфліктних частинах файлів:

- '<<<<<<<<< HEAD' - початок конфліктної частини з поточної гілки
- '==============' - розділяє кінець конфліктної частини з поточної гілки та початок конфліктної частини з гілки, яку об'єднуємо 
- '>>>>>>>>>' - кінць конфліктної частини з гілки, яку об'єднуємо

## Опис прийнятого рішення

Конфліктна частина файлу було замінена строкою, що є спільною для обох гілок, після чого даний файл
було проіндексовано командою 'git add' та на основі чого буде завершено merge-коміт.
