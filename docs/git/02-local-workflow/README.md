## Working tree
 
Являє собою одну окрему версія проекту, взяту зі сховища

## Staging area

Являє собою файл, що зазвичай знаходиться в директорії Git і містить інформацію про те, що буде збережено у наступному коміті.

## Repository

Частина проекту під управлінням Git, де система зберігає метадані та базу даних об’єктів вашого проекту.

## Основні команди

- 'git switch -c' - створює нову гілку та переключає на неї
- 'git status' - показує поточний стан робочого катологу
- 'git diff' - показує зміни, які не були додані до staging area
- 'git add' - додає зміни до staging area
- 'git restore' - скасовує незакомічені зміни в файлі
- 'git commit' - створює коміт

## Безпечне скасування локальних змін

Для скасування незакомічених змін у файлі, використовується команда 'git restore'
