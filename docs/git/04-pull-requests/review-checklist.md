## Scope

- Зміни відповідають опису задачі та не містять зайвих файлів або змін.
- Усі необхідні файли додані до PR.
- Немає випадкових змін, тимчасових файлів або секретів.

## Commit history

- Коміти мають зрозумілі та змістовні назви.
- Історія комітів читабельна та відповідає етапам виконання задачі.
- Немає зайвих або випадкових комітів.

## Запуск

- Проєкт успішно запускається після отримання змін з PR.
- Інструкції із запуску актуальні та зрозумілі.
