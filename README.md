# Igor — Stakeholder Onboarding

## Власник

Igor

## Мета онбордингу

Підготуватися до першої реальної задачі у Stakeholder через послідовні практичні модулі з Git, TypeScript, React, Laravel та Inertia.

## Призначення

apps/ - містить основні застосунки проекту (frontend + backend)
exercises/ - містить практичні завдання для закріплення матеріалу та перевірки отриманих знань.
docs/ - документація проекту, опис статусів, шаблони блокера та щоденного звіту
